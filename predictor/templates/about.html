ℹ️ About This Project

🎯 Project Overview

This Diabetes Predictor is an advanced machine learning application designed to help with early detection and risk assessment of diabetes. It uses state-of-the-art algorithms to provide accurate predictions based on comprehensive health metrics.

🤖 Machine Learning Models

1. Logistic Regression

A linear classification algorithm that models the probability of diabetes occurrence. It's interpretable and provides clear probability scores for predictions.

2. Random Forest

An ensemble learning method that combines multiple decision trees to improve prediction accuracy. It captures complex patterns in the data and provides robust predictions.

📊 Dataset

The models are trained on the Pima Indians Diabetes Dataset, which contains health metrics from 768 individuals. The dataset includes features such as:

  • Number of pregnancies
  • Glucose level
  • Blood pressure
  • Skin thickness
  • Insulin level
  • Body Mass Index (BMI)
  • Diabetes pedigree function
  • Age

⚠️ Disclaimer

This tool is for educational and informational purposes only. It should NOT be used as a substitute for professional medical advice, diagnosis, or treatment. Always consult with a qualified healthcare professional for medical concerns.

🛠️ Technology Stack

  • Backend: Django (Python Web Framework)
  • Machine Learning: Scikit-learn
  • Data Processing: Pandas, NumPy
  • Frontend: Bootstrap 5, HTML5, CSS3
  • Database: SQLite

📈 Model Performance

Both models are trained and evaluated using standard machine learning metrics including accuracy, precision, recall, and F1-score. The models achieve high accuracy on test data and are continuously validated for reliability.
